CHATGPT API CREDIT CHECK
OpenAI’s current documentation describes an API-credit benefit for eligible paid Pro and Business subscriptions. The user’s current tier, eligibility, linked organization, available balance, and activation status have not been verified.
Before buying API credit: inspect ChatGPT Settings → Billing → API credits, or API Platform Billing. The receiving API organization must be the one used for the app.
Treat API consumption separately from interactive ChatGPT use. A subscription alone does not wire the website to an API. Credits may expire and must be monitored.
Use a small test budget and application-level usage controls. Provider alerts are not automatically a hard spending stop.
Do not paste keys into either project chat. Claude should specify secret names and the provider’s secure configuration steps.

STAGE 1 — SMALL WORKING PILOT
Proposed architecture for Claude to evaluate:
- Cloudflare Workers for the web/backend.
- D1 for structured jobs and approvals.
- R2 only where private attachments are required.
- Queues or Workflows for durable processing.
- Resend for transactional email.
- Server-side OpenAI API access for Catherine, with the runtime model selected after verification and tests.
- An established authentication solution.
This is a candidate, not a requirement to buy these exact products. Claude must include dependencies and overages in the estimate and explain any alternative.

Verified vendor baselines:
- Cloudflare Workers has a free tier. Its paid plan begins at a minimum $5/month per account; usage can add charges. Database, storage, workflow and queue details must be included in the complete estimate.
- Resend’s displayed free transactional tier includes 3,000 emails/month with a 100/day limit. Domain verification and sender setup still need to be completed.
- Domain: select the public business name first. Obtain a live registration and renewal quote. A provisional allowance of $15–25/year is a planning allocation, not a verified quote for an available domain.
- API: use eligible existing credits first if available. Otherwise propose a small explicit test allowance and report measured cost per completed job. No universal “unlimited AI” assumption.
- Payments: invoice generation does not require a new paid invoicing subscription. Price any payment-processing integration separately before taking real payments.

Planning envelope:
Use $5–25/month as a provisional target for the initial hosting plus modest metered runtime, excluding existing chat subscriptions, domain registration, mobile service, payment fees, taxes, and field expenses. This is a design target, not a vendor quote or guaranteed all-in cost. Claude must return a credible itemized estimate and an overage/failure policy before activation.
